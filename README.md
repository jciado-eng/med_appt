# StayHealthy 🏥

StayHealthy is a modern healthcare management and medical appointment booking web platform, developed as a Single Page Application (SPA) using **React** and **Vite**.

## ✨ Key Features

*   **User Authentication**: Complete Login and Registration systems with client-side data validation.
*   **Instant Consultation**: Easy doctor search filtered by specialization along with immediate appointment booking workflows.
*   **Notification System**: Real-time on-screen toast components to remind users of upcoming scheduled consultations.
*   **Profile Management**: A dedicated dashboard allowing users to view, manage, and dynamically update their profile and contact information.
*   **Reviews & Feedback**: An interactive evaluation board enabling users to leave 1-to-5 star ratings and written reviews for doctors.
*   **Patient Reports**: A centralized reports section to view medical files in a separate tab or download them directly as PDF attachments.

## 🛠️ Tech Stack

*   **React** (Functional components, Hooks including `useState`, `useEffect`, and `useNavigate`)
*   **Vite** (Next-generation ultra-fast frontend build tooling)
*   **React Router DOM** (Dynamic client-side routing for seamless page switches)
*   **CSS3** (Responsive grid layouts, fluid interactive hover items, and UI modals)

## 📦 Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/jciado-eng/med_appt.git
   ```

2. Navigate into the project directory:
   ```bash
   cd med_appt
   ```

3. Install all required dependencies:
   ```bash
   npm install
   ```

4. Launch the local development server:
   ```bash
   npm run dev
   ```

5. Build the application for production and run the live preview environment:
   ```bash
   npm run preview
   ```
